公允收益率 Fair% — 我们的定价模型给出的收益率
= (CGB国债收益率 + CCS基差) + 信用风险补偿 + 发行人个性 + LGFV省份差异 + 交易摩擦

公允净价 Fair$ — 把Fair%代入标准债券公式折现出来的理论价格

① 地基：CGB国债收益率（v3.6中国国债曲线）

境内中国国债(China Government Bond)是无风险基准
ChinaBond每日公布：3M~30Y 11个关键期限节点
当前：1Y 1.17% -> 5Y 1.45% -> 10Y 1.74% -> 30Y 2.23%
数据来源：中债估值中心(chinabond.com.cn)

② 信用利差矩阵：查表

每个级别x行业x期限，市场要求多少额外补偿。就像一个巨大的Excel表格：
AA+央企金融 5年期 -> 大概加100bp
BBB+城投 3年期 -> 大概加200bp
怎么来的：DMI平台几千只债 -> 按评级x行业x期限分堆 -> 每只债的RP收益率减同期国债 -> 取中位数 -> 写入矩阵。
47组，覆盖 AAA~CCC x 主权/政策/央企/城投/科技/地产/外资。
注意：矩阵底层用DMI RP校准，RP本身就偏低~35bp，所以矩阵值整体偏紧。后面用发行人调整和期限溢价补回来。

③ 个性：发行人调整

同样是A+央企金融，你这家比平均贵还是便宜
市场实际给你的利差 - 表格查出来的基准利差 = 你的个性溢价
比如山东和晟比同类城投平均贵118bp——市场在惩罚它
摩根大通比同类银行便宜46bp——市场更信任它
数据不够或太旧的话，调整幅度自动打折扣

④ 银行也要分三六九等

以前金融一个筐装所有：工行和融资租赁用同一个利差
现在拆开：政策银行（国开行等）加不超20bp
五大行股份行给出30bp优惠；租赁券商至少加100bp
41个金融发行体因此被重新定价

⑤ 中国特色：城投债省份分层

同一个评级A的城投债，上海的和贵州的，市场利差能差500bp
我们按省级财政健康度分了四档：
强省（沪京粤浙苏）利差优惠15~30bp
弱省（黔滇甘辽吉黑）利差惩罚30~50bp
基于各省债务率、财政收入质量、转移支付依赖度等公开财政数据
这不是评级公司给的——是我们从财政数据里算的

⑥ 摩擦：流动性溢价

按市场数据可得性+板块分层：
有市场报价->1bp | IG无报价->4bp | HY无报价->8bp
板块乘数：主权/政策x0.5 央企金融x0.8 城投x1.5 地产科技x2.0
实际区间：0.8bp（大国开行）~16bp（HY小地产）

防呆：长端折扣

期限超过15年的债，利差自动打折
15年打7折、20年打5折、25年以上打3.5折
基于IG样本实证（10Y+仅221条观测），HY适用性待验证
因为30年债的校准样本太少，外推容易失真；
真实市场中顶级名字的30年利差远低于线性推测值

⑦ v3.7：中长端期限溢价

实测7Y+模型信用利差系统偏低~200bp
市场对长端债券要求期限补偿，短端矩阵值不够
7-10Y +80bp | 10-15Y +60bp | 15Y+ +40bp
效果：整体MAE 34.6->34.8bp（持平），胜率57->60%
A+评级偏误-18bp->0bp（对称化），BBB+改善27->17bp
基于139对Bloomberg CMU实时报价验证（0119/0123/0126/0130）

⑧ OAS：含权债要单独算

永续债（PERP）是永远不还本、但发行人可以提前赎回
就像房东说租约永不过期，但我可以在第5年叫你搬走
这个赎回权对发行人值钱，对投资人不利——所以要额外加价
怎么算：Vasicek利率模型模拟500条未来利率路径 -> 看每条路径上利率降到票息x0.8以下时发行人是否按100赎回 -> 含权价 vs 不含权价的差额就是OAS（bp）
当前2只PERP：创兴银行+179bp、珠海华发+264bp

防呆：主权归零

政府自己发的债，不能给自己加风险溢价
适用财政部、省市政府、超国家机构
比如财政部曾被算出+127bp -> 强制归零

CNH Fair Value Engine — 完整汇报

一、缘起：为什么要做这个模型

离岸人民币债券市场（点心债）2025年发行量超3,000亿港元，2026年继续高速增长。但国际定价供应商（Bloomberg BVAL、LSEG）对CNH债覆盖薄弱：大量城投债仅单一数据源、缺乏省级财政分层、定价过程不透明。投资者需要一个可追溯的定价基准——每一bp都能解释来源。

二、方法论的来源：我们向谁学习

Bloomberg BVAL — 多源共识定价。当单一债有多个做市商报价时，BVAL取共识中位数。我们借鉴了这个思想，但更进一步：BVAL给你价格不解释，我们把每个来源的权重和分歧度都展示出来。

LSEG/Refinitiv — 板块子模型。不同板块的债券用不同的定价因子。我们借鉴了分板块建模架构。

S&P IHS Markit — 可比债券匹配。当目标债没有直接成交时，用最相似债券的利差来推断。

ICE Data Services — 公允价值区间+买卖价差。不只给一个点估值，而是给出置信区间。

SEC对Bloomberg的处罚案例（2022） — 输入多样性监控。Bloomberg因单一数据源导致BVAL偏离被SEC罚款500万美元。我们吸取教训。

CFETS（中国外汇交易中心） — CCS基差实证。最初用的硬编码估计值不仅数值不对，方向都是反的（差80-90bp）。接CFETS每日发布数据后实现了实证校准。

三、模型架构

核心公式：Fair% = (CGB国债收益率 + CCS基差) + 信用利差(142组矩阵) ± 发行人调整(81个) ± LGFV省级分层(31省) + 流动性溢价(分层) + 期权调整

三层架构：① 基准层（NS曲线+矩阵，决定90%结果）-> ② 增强层（发行人+LGFV，Bloomberg和LSEG没有的）-> ③ 质量层（多源共识、异常检测、输入多样性）

信用利差矩阵是核心。从DMI平台实际成交数据，按评级x板块x期限分组取中位数。再做残差分析提取发行人偏离。按省级财政健康度建立LGFV四层分级。三项全自研，DMI实证校准。

四、关键改进历程

CCS基差进入核心定价（v3.1）：调整后rf = CGB国债 + CCS基差。经济含义：全球投资者用USD换CNH的真实资金成本。

发行人调整零中心化修正：SOE金融子板块floors造成了单向偏差——76个正向调整vs仅1个负向。修正：校准末尾对所有调整做加权零中心化，RICH从59%降至25%。

收益率曲线改用原始插值：Nelson-Siegel拟合将174bp利差压扁到125bp。改为cbonds原始数据线性插值，恢复真实曲线形态。

流动性溢价分层：原来固定1.5bp。改为按市场数据可得性+板块分层：有报价1bp、IG无报价4bp、HY无报价8bp，板块乘数0.5x~2.0x。区间0.8~16bp。

SOE金融利差上限：央企金融桶混入租赁/AMC等宽利差发行体，拉高中位数。加评级上限：AAA≤60bp、A≤120bp、BBB≤200bp。

仅保留中国发行体：剔除1,356只外资债，聚焦中资发行人964只。

五、当前成果

覆盖：964只中国离岸人民币债券（680只国际评级 + 284只国内/NR评级），IG 678只、HY 286只

矩阵：142组评级x板块x期限基准利差，81个发行人特定调整，31省LGFV四层分级

自动化：六步全自动流水线 — 新DMI数据->重建CSV->重校准利差矩阵->抓CFETS CCS->更新发行人调整->全量估值->Web热重载。无人值守。

约束：评级上限（AAA±50bp、A±200bp）、长端折扣（15Yx0.7、20Yx0.5、25Y+x0.35）、主权归零、soe_financial利差上限

六、已知限制

加法分解假设：七分量简单相加，未建模交互效应（评级x板块x期限）。极端市场下可能偏差

长端样本稀疏：10Y+仅221条观测，折扣系数基于IG实证，HY适用性待验证

置信度权重的经验性：N/20分母、新鲜度衰减函数（30d->1.0, 90d->0.8, 180d->0.5）为经验设定，未做网格搜索优化

LGFV分层的静态性：省级财政健康度基于公开数据，四级阈值需定期复核

CCS基差的传导敏感度：美债变化通过CCS进入估值，短端敏感（±15bp/50bp US move）

SOE金融子板块分类精度：金融板块内部分类依赖发行人名称关键词，个别发行体可能归类错误

无盘中实时数据：当前为日终快照模式，DMI数据依赖手动导出xlsx

信用利差矩阵的空洞：142组中有部分组合样本不足（N<5），依赖相邻评级或板块的外推
